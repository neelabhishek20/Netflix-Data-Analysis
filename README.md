# Netflix Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python, Pandas, and Matplotlib.

The objective is to uncover trends in Netflix content, including content types, ratings, countries, genres, and yearly growth patterns.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Dataset

Netflix Movies and TV Shows Dataset from Kaggle.

## Data Cleaning

- Handled missing values
- Checked duplicate records
- Converted date columns into datetime format
- Created new features:
  - year_added
  - month_added
  - day_added
  - duration_num

## Analysis Performed

### 1. Movies vs TV Shows
Analyzed the distribution of content types.

### 2. Top Countries
Identified countries contributing the most content.

### 3. Ratings Distribution
Analyzed content ratings across Netflix titles.

### 4. Content Added Per Year
Studied Netflix's growth trend over time.

### 5. Top Genres
Explored the most common genres on Netflix.

## Key Findings

- Movies significantly outnumber TV Shows.
- The United States contributes the highest amount of content.
- India is the second-largest contributor.
- TV-MA and TV-14 are the most common ratings.
- Netflix experienced rapid growth between 2016 and 2019.
- Content additions peaked in 2019.
- Drama, Documentaries, and Stand-Up Comedy are among the most popular genres.
